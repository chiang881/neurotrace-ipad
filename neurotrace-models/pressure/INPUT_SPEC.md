# 输入规格、范围、单位和量纲影响

## 1. 模型真正接收什么

Core ML 模型只接收 72 维特征向量，不接收原始轨迹。

```text
features: Float32[72]
```

72 个特征来自测试 `0`（静态螺旋）和测试 `1`（动态螺旋）的轨迹汇总，包含：

- 压力：中位数、IQR、变化率、频域能量等
- 握笔角：圆统计、角速度等
- 运动学：速度、加速度、加加速度、路径长度、曲率、转向率等
- 频域：运动和压力在 3-8 Hz、4-6 Hz 的能量比例、主频、谱熵
- Z 轴：`z_p90`、`z_rate_abs_mean`、`z_zero_ratio`

完整顺序见 `schema/feature_schema.json`。

## 2. 如果主程序输入原始点序列

每个采样点建议结构：

```text
x: Double
y: Double
z: Double
pressure: Double
grip_angle: Double
timestamp: Double
test_id: Int
```

训练数据原始列定义：

```text
X ; Y ; Z ; Pressure ; GripAngle ; Timestamp ; Test ID
```

本模型使用 `test_id = 0` 和 `test_id = 1`。`test_id = 2` 没有进入 all-common 模型。

## 3. 原始输入训练范围

以下是训练数据中的观测范围，用于 sanity check，不是硬性截断规则：

| 字段 | 训练范围 | 中位数 | 单位/解释 |
|---|---:|---:|---|
| `x` | `-5` 到 `1007` | `231` | 数位板坐标单位 |
| `y` | `-15` 到 `569` | `232` | 数位板坐标单位 |
| `z` | `0` 到 `1023` | `0` | 原数位板 Z/笔尖高度通道 |
| `pressure` | `0` 到 `1023` | `688` | 原数位板压力刻度 |
| `grip_angle` | `0` 到 `3580` | `1180` | 十分之一度，`1180 = 118°` |
| `timestamp` | 不要求绝对值一致 | - | 毫秒；模型只用相对时间差 |

测试时长训练范围：

| 测试 | 样本数 | 时长范围 | 中位时长 |
|---|---:|---:|---:|
| `0` 静态螺旋 | 76 | `3.7s` 到 `103.4s` | `18.2s` |
| `1` 动态螺旋 | 72 | `3.4s` 到 `78.8s` | `17.1s` |

采样间隔通常约 `7-9 ms`，特征工程会重采样到 `110 Hz`。

## 4. 特征输入范围

逐特征训练范围在：

```text
schema/feature_ranges.csv
```

主程序可以用它做日志告警：

- 若某个特征超出 `p01-p99` 很多，说明输入单位或采集流程可能变了。
- 不建议强行 clip 到训练范围，因为树模型对阈值敏感，clip 可能掩盖采集错误。

## 5. 单位和范围会不会影响结果

会，而且影响很大。

### 坐标尺度会影响

速度、加速度、加加速度、路径长度和曲率都由 `x/y/timestamp` 推导。

如果主程序把坐标从 `400x400` 改成 `1000x1000`，速度和加速度会按比例变大，模型输出会变。必须固定坐标系，或在特征工程前统一映射到训练时的逻辑坐标。

### 时间单位会影响

训练特征把时间戳差值按毫秒处理，再换算成秒。

如果输入 timestamp 是秒但被当成毫秒，速度会缩小约 `1000` 倍；如果输入是纳秒但未换算，速度会严重失真。主程序必须传毫秒，或在特征工程入口统一转换。

### 压力尺度会影响

训练压力范围是 `0-1023`。如果主程序压力是 `0-1`，必须乘以 `1023` 后再做特征。压力中位数、IQR、变化率和频域能量都会受影响。

### 握笔角单位会影响

训练 `grip_angle` 是十分之一度。若主程序拿到的是弧度或度，需要转换：

```text
degree -> degree * 10
radian -> radian * 180 / pi * 10
```

角度特征使用圆统计和角速度，单位错会明显影响结果。

### Z 信号会影响

all-common 模型包含 `Z` 特征。如果没有等价 `Z` 信号，不要填 `0`。填 `0` 会让模型以为笔尖高度长期为零，这不是缺失值，而是一个强信号。缺失应填 `Float.nan`，但如果整个部署环境都没有 Z，更好的方案是训练不含 Z 的模型。

### NaN 和 0 不等价

XGBoost 学到了缺失值默认分支。无法计算的特征应传 `Float.nan`。传 `0` 会被当成真实 0，可能改变分类路径。

## 6. 输出解释

```text
classProbability[1]
```

是“输入轨迹更像训练集中帕金森模式”的概率分数。不是确诊概率，也不是早期帕金森医学风险。

推荐 UI 文案：

```text
运动模式筛查分数：xx%
仅供研究参考，不能替代医生诊断。
```

## 7. 最小验收

主程序对接后，用 `examples/C_0001_feature_vector.json` 喂模型，应得到较低的 `classProbability[1]`；用 `examples/P_02100001_feature_vector.json` 应得到较高的 `classProbability[1]`。

因为示例 JSON 用 `null` 表示可移植缺失值，进入 Core ML 前要转为 `Float.nan`。
